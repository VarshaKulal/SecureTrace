# SecureTrace

### Multilayer Document Fingerprinting for Insider Leak Attribution

SecureTrace is a document security system that protects sensitive files using multilayer fingerprinting. It detects leaked documents, tracks their source, and helps identify the likely recipient responsible for the leak.

## Features

* 🔐 Document fingerprint generation
* 📄 Secure document tracking
* 🔍 Leak detection
* 👤 Source/recipient identification
* 📊 Leak analysis and reporting

## Technologies

* HTML, CSS, JavaScript
* Node.js & Express.js
* MongoDB
* Git & GitHub

## How It Works

```Workflow
Upload Document
      ↓
Generate Fingerprint
      ↓
Track Recipient
      ↓
Detect Leaked Document
      ↓
Compare Fingerprints
      ↓
Identify Likely Source
```
